# homebrew-tap

Homebrew formulae for [beduldul](https://github.com/beduldul)'s tools.

## Install

```sh
brew install beduldul/tap/ai-policy
```

Or tap first:

```sh
brew tap beduldul/tap
brew install ai-policy
```

## Formulae

| Formula | What it does |
|---|---|
| `ai-policy` | Check whether a repository accepts AI-assisted contributions, before you open the pull request |
